Kurumi 算力行情终端 · 四版视觉方案

把 macOS 的 CPU / GPU / 内存 / 磁盘 / 网络 / 进程搬进 A 股行情终端的界面语言。四版共用同一套九宫格信息架构与同一组数据，差别在配色、密度与布局策略 —— 选的是视觉方向，不是重新设计信息结构。

A · 深色九宫格 —— PerfTicker 形态直译

最忠实于原项目的视觉：纯深色底、红涨绿跌遵循 A 股习惯、字号压到 10–11px 的高密度排版。九个区块同屏铺满，一眼看到全部维度。代价是对显示宽度有要求，低于 1180px 会开始折叠右侧盘口。

B · 窄屏堆叠 —— Mini App 面板原生适配

Mini App 跑在 MCode 右侧面板里，宽度常常只有 450px 上下。这一版把九宫格竖向拆开：指数条收成 2×2、主图独占一屏、盘口与逐笔改为纵向堆叠、进程表裁掉次要列。配色沿用 A 的深色，但强调色换成蓝以区分定位 —— 它是「适配版」而非「主版」。

C · 浅色研报 —— PerfTicker 的默认主题

原项目默认其实是浅色主题，深色要手动切。这一版把浅色做扎实：白底、极细的分隔线、克制的红绿、留白比 A 版宽一档。白天长时间挂着不刺眼，适合当常驻看板。代价是少了一点「终端」的暗室气质，视觉冲击弱于 A。

D · 琥珀 CRT —— 复古行情机

风格化最激进的一版：磷光琥珀单色、叠加扫描线、文字带辉光、圆角全部压到 3px 模仿老式终端机。跌色用青绿而非纯绿，保持在单色体系内不打架。气质最强，但也最容易看腻 —— 长时间盯盘的疲劳感和「到底在不在认真显示数据」的疑虑都是真实代价。

怎么选

四版的取舍集中在三件事：信息密度、暗室气质、以及它到底要在多宽的地方活着。

方案强在弱在适合
A 深色九宫格 视觉冲击最强，信息一屏打尽，与原项目气质完全一致 吃宽度，窄屏折叠后右侧盘口会消失 外接显示器上全屏挂着，当主看板
B 窄屏堆叠 唯一能在 MCode 面板里完整成立的版本，纵向滚动自然 同屏信息量约为 A 的六成，进程表列被裁 日常就在 MCode 里开着，不切窗口
C 浅色研报 白天友好，留白舒展，长时间看不累 终端的暗室感没了，第一眼不如 A 抓人 和浅色工作环境搭配，当第二块屏
D 琥珀 CRT 气质独一无二，截图传播力最强 扫描线和辉光长期看会累，风格压过数据本身 想要一个「玩具」而非工具

也可以组合：A 做桌面主版 + B 做面板适配版，主题变量本来就是同一套 CSS token，切换成本很低。C 和 D 同理，只是换 --up / --down / --bg 几个值。真正要定的是主视觉走哪一版。
